myjobs/backend/app/api/
- **FastAPI**: Serves the specialized endpoints required by the web frontend.
1. POST /api/v1/profile/upload-cv: Recebe o PDF, extrai texto e salva no RAG.
2. POST /api/v1/jobs/discover: Recebe a URL da lista, chama fetch_job_list_raw,
passa pela IA para extrair o JSON de vagas e salva no Banco de Dados.
3. POST /api/v1/jobs/{job_id}/analyze: Busca a URL no Banco, chama
fetch_job_description_raw, faz o match com o RAG e retorna a nota/análise.

myjobs/backend/app/core/
# LangChain Orchestration
Powered by **LangChain** and **Google Gemini (1.5 Pro)**.
- **Agentic Chat**: A conversational interface where the AI uses the defined
tools to answer questions and perform actions.
- **High Context**: Utilizing Gemini's large context window to compare
multiple job descriptions with detailed professional profiles.
Usado para a análise final de match ("Devo aplicar para essa
vaga?") e para escrever o currículo personalizado, onde a nuance e a criatividade são
cruciais.
